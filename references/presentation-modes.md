# 开始制作时选择呈现方式

新任务在内容理解、分镜和生图前，先检查本次明确指令或当前专辑/任务已确认的选择。已选择就沿用，不重复问；仅更新技能、估算成本、研究模板或恢复已有任务时不发起制作方式选择。

缺少选择时只问一个问题，并结合内容给出推荐：

> 这条音频想用哪种方式呈现？
> - 网页动画（Hyperframes）：图像动画开头，正文用可复用知识模板，适合心理效应、知识解释和概念关系，也能插入生成图片。
> - 纯图片：以人物、场景和氛围图讲述，适合《武则天》这类历史人物与故事内容。

推荐不是自动选定。用户回答前可读音频信息、正文与既有专辑档案，不执行依赖该选择的生图或渲染。已有明确“用网页动画”“按上一条纯图片方式”就是选择证据。用户让你自行决定时，根据内容决定并记录这项授权，不再追问。

在本次 selection.config / job/config.json 中保存：

```json
{"presentation":{
  "mode":"hyperframes",
  "choice_evidence":"填写本次用户选择或明确沿用的真实指令",
  "opening_style":"auto",
  "image_inserts":true
}}
```

`mode` 为 `hyperframes` 或 `images`。`opening_style` 为 `auto` 或六种推荐风格之一；用户指定其他已下载风格时也可使用。`image_inserts` 允许按内容使用插图，不表示必须生图。只有用户说明整专辑沿用时，才把选择保存为专辑偏好；否则仅作用于当前任务。

## 两条路线

| 内容 | 建议 | 动作与资源 |
|---|---|---|
| 心理、认知、知识解读 | 网页动画 | 第一正文分镜用 motion-showreel 图像动画；随后用知识模板；人物/事件/物件需要具体化时插入生成图片 |
| 历史人物、文化叙事、情节故事 | 纯图片 | 使用现有故事生图、原声字幕、专辑底图与剪映/OpenFilm组装；不强制加代码动画开场 |
| 用户已有明确选择 | 尊重选择 | 不因题材标签推翻选择；网页动画内的故事段落可以插图 |

网页动画读 [web-animation.md](web-animation.md)，纯图片读原 [workflow.md](workflow.md)。约7秒一图、十分钟80–100张仅属于纯图片路线，不用于网页动画与插图预算。

呈现方式和输出格式分别记录。`output_backend=capcut|openfilm` 仍是原纯图片组装器的后端；不要把 `hyperframes` 填进这个字段。做视频默认只交核验过的剪映草稿与素材；明确选择网页/OpenFilm时交对应可编辑工程，网页附已验证预览链接与启动入口。delivery.target默认project；仅明确要求MP4或仅预览时填写对应target和choice_evidence。若还需剪映或OpenFilm草稿，按网页路线说明处理已经渲染的片段或原生网页层，不能直接调用仅支持图片交接的旧组装器冒充已接入。

旧任务没有 presentation 字段时，脚本保留原纯图片行为，避免破坏恢复；新任务仍须由执行者完成入口选择。切换模式复用音频、字幕和已有图片，在新工程目录制作，不覆盖原草稿。
