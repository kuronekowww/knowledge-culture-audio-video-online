# 封面请求与超时排查

成品使用 1080×1920。当前 GPT Image 2 代理的随附接口说明列出 1024×1024、1024×1536、1536×1024、1024×2048 和 2048×1024 五档。正式封面单次 POST /generate 传 prompt、size=1024x1536、quality=high、n=1、include_b64=false。通过标题确认后才提交。结果下载后保留原图，全宽等比适配 9:16，两端延展背景。审图看完整竖图和中央 3:4 的标题、简称及主体。历史已完成的 1080×1920 封面允许继续读取；新付费请求在发送前检查接口尺寸。

旧版把交付画布尺寸当作请求尺寸。《武则天》第 2、3、5、6 集留有超时或 504 记录。在同一代理的既有共享缓存中，有 6 张 1024×1536 竖图成功记录；1080×1920 的外部工具导入记录不能证明该尺寸在此代理可用。2026-11-10 以真实获准的两行标题提交一张 1024×1536 的 low 封面，代理报告 gpt-image-2，生成 33.5 秒、含下载和首轮适配共 36.9 秒。复核原图后仅在本地改进了竖屏构图。单次成功不代表每次都能在相同时间内完成。

若仍超时，看该请求的 request.json。区分本机连接、等响应超时和服务端 HTTP 504，查看提交尺寸、等待上限、实际耗时和服务提供的请求编号。服务未提供编号就保持空值。已有结果 URL 时只恢复下载；生成结果未知时由服务端核实后再决定是否重发。调高读取超时并不能解除服务端网关的限制。请勿打印 token 或完整签名图片地址。

当前脚本支持逐图quality：manifest顶层仍可low，封面行写`quality: high`，正文行沿用low；实际请求与缓存指纹都按逐图档位绑定。`--quality`是显式整批覆盖。已有回执的旧图不因升级默认值而自动收费重做；上文low耗时只是历史实测，不代表high的耗时与服务支持已测。高档不受支持就报告，不能默降。
